How Rei Meets Each Criterion

Safety & Responsibility

WAICY emphasizes AI systems that prioritize human safety. Rei has a multi-layered safety architecture covering self-harm prevention, content filtering, and crisis intervention.

  • ✓ Multi-tier content safety filter
  • ✓ Self-harm intervention protocol
  • ✓ Eating disorder language detection
  • ✓ Radicalization & misinformation shield
  • ✓ Grooming pattern recognition
  • ✓ Zero data commodification policy

Human-Centered Design

Rei is built around genuine teen needs — emotional support, privacy, productivity, and safety. Every feature was designed from user-centered research and empathy mapping.

  • ✓ Emotional check-in system
  • ✓ Conversational memory for continuity
  • ✓ Judgment-free conversational space
  • ✓ 24/7 availability — including 2am
  • ✓ Grounding & breathing techniques
  • ✓ Persona consistency (Rei is steady & warm)

Innovation & Creativity

Rei introduces novel approaches to AI companion design — combining emotional continuity, safety-first architecture, and maternal-toned persona into a cohesive living experience.

  • ✓ Memory-weighted emotional continuity
  • ✓ Tiered emotional routing engine
  • ✓ Maternal-toned AI persona (unique voice)
  • ✓ Crisis-aware intervention protocols
  • ✓ Privacy-first local architecture
  • ✓ Multi-page immersive web experience

Technical Implementation

The Rei website demonstrates full-stack web development skills — vanilla HTML/CSS/JS with no frameworks, featuring particle systems, parallax, interactive diagrams, chat simulation, and responsive design.

  • ✓ Vanilla JS — no frameworks
  • ✓ Particle background system (canvas)
  • ✓ Scroll-triggered animations (IntersectionObserver)
  • ✓ Interactive chat simulator
  • ✓ Parallax scrolling & floating orbs
  • ✓ Light/dark theme toggle + localStorage
