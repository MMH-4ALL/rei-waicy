System Components

Conversational Memory System

Rei's memory system maintains persistent conversation history, enabling true continuity across sessions. Unlike simple chat logs, Rei's memory is structured, weighted, and selectively retrieved based on context relevance.

  • Short-term context window: Current session context maintained in working memory for immediate relevance.
  • Semantic memory store: Key facts, preferences, and emotional patterns extracted and stored persistently.
  • Importance weighting: Emotionally charged or repeated topics are weighted higher for retrieval priority.
  • Recall triggers: Automatic retrieval when related topics appear in new conversations.
  • Privacy boundaries: Sensitive information is tagged and never used for cross-context purposes.

Tools & Capabilities Layer

Rei's tools layer enables real-world utility — from finding files to setting reminders, she acts as a genuine productivity partner, not just a conversational engine.

  • File search: Intelligent file finder that searches by name, type, date, or content keywords.
  • Reminder system: Natural-language reminder creation with timed notifications.
  • Calendar integration: Schedule viewing and event creation support.
  • Web search: Safe, filtered web search for homework and research tasks.
  • Note-taking: Persistent note storage with categorization and retrieval.
  • Tool safety guard: Every tool invocation is checked against the safety layer before execution.

Safety & Content Filtering

The safety layer is Rei's most critical component. It intercepts all input and output, scanning for harmful content patterns and triggering appropriate intervention protocols.

  • Self-harm detection: Recognizes indicators of self-harm ideation and triggers safe messaging protocol.
  • Eating disorder patterns: Detects pro-eating-disorder language and body image distortion cues.
  • Radicalization signals: Identifies escalating extreme viewpoints and redirects to safe resources.
  • Misinformation flagging: Flags harmful false claims with corrections and source links.
  • Harassment detection: Identifies bullying, hate speech, and grooming patterns.
  • Intervention protocols: Tiered response system — from gentle redirect to crisis resource provision.

Decision & Response Logic

Rei's reasoning engine determines what kind of response to give based on emotional state, conversation context, user history, and safety assessment.

  • Emotional routing: Determines if response should be informational, emotional support, grounding technique, or safety intervention.
  • Persona alignment: Every response is checked against Rei's persona — warm, steady, maternal energy.
  • Memory integration: Past relevant conversations are woven into responses naturally.
  • Tool decision: Determines when to use a tool vs. when to respond conversationally.
  • Output safety check: Final output passes through safety filter before delivery to user.
